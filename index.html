AI Chess Bot

A full-stack AI Chess Bot website using HTML, CSS, JavaScript, Python (Flask), and PyTorch. Uses the Minimax Algorithm with Alpha-Beta Pruning to generate intelligent chess moves efficiently. It has multiple AI difficulty levels including Beginner, Easy, Medium, Hard, and Expert by dynamically adjusting search depth and evaluation complexity. It features an interactive click-to-move chess interface with responsive UI and real-time gameplay.

Fake Profile
Detection System

A full-stack web application that detects fake social media profiles using machine learning. Trained a Random Forest classifier (200 estimators, 16 behavioral features) on synthetic profile data to classify accounts as real or fake with confidence scoring. Developed a REST API using Flask that auto-saves every analysis to a MySQL database, and built a dark-themed frontend dashboard in vanilla HTML/CSS/JS featuring real-time analysis results, profile history management, and activity statistics.

Automated University
Club Policy Checker

UniClub is a full-stack web application that automates the registration and management of university clubs using a Rule-Based Expert System inspired by formal AI concepts. The system translates written university regulations into formal IF-THEN production rules and uses an inference engine to evaluate every club application automatically, generating a detailed violation trace that explains exactly why an application passes or fails. Built with a Node.js and Express backend, a MySQL relational database, and a pure HTML/CSS/JavaScript frontend, the project features three role-based portals — a public application portal, a university administrator dashboard, and a club management portal.
